AFTER EDITING:
===================================================================

1. Click OK to save the function
2. You should see the Open_Loop_Controller block now has a 5th output port (may need to resize block to see it)
3. Save the model (Ctrl+S)
4. Re-deploy to hardware

The Dashboard will still show the old "Offset (Avg)" value, which is just rotor position.
Once you run CL FOC 100 RPM, the offset_foc is calculated during the 1.5s ramp phase and used for alignment.

The TRUE encoder offset is the one inside offset_foc - it will be stable during closed-loop operation!
