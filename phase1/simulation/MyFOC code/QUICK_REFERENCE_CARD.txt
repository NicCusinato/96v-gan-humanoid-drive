┌─ CRITICAL SIGNAL VALUES & RANGES ──────────────────────────────────────────┐
│                                                                              │
│  Phase Currents (Ia/Ib/Ic):                                                 │
│    Raw ADC: 0-4095 counts → Actual: ±20 A                                  │
│    Offset (powered 48V): ~2041-2059 counts                                  │
│    Example: adc_a=3000 → Ia = (3000-2041)*(3.3/4095)/(0.002*20) ≈ 12.3 A │
│                                                                              │
│  d/q Currents (Id/Iq) - Already Scaled:                                    │
│    Range: ±10 A                                                             │
│    Scaling factor: 3276.7                                                   │
│    To extract: Id_amps = packet_value / 3276.7                             │
│                                                                              │
│  Voltage Commands (Vd/Vq) - Already Scaled:                                │
│    Range: ±5 V                                                              │
│    Scaling factor: 6553.4                                                   │
│    To extract: Vd_volts = packet_value / 6553.4                            │
│                                                                              │
│  Rotor Electrical Angle:                                                     │
│    Range: 0 to 2π radians                                                   │
│    Packet scaling: 0-65535 = 0-2π                                          │
│    To extract: theta_rad = packet_value / 65535 * 2π                      │
│                                                                              │
│  Speed:                                                                       │
│    Raw: ±2000 RPM (int16)                                                   │
│    Example: speed_rpm = typecast([pkt(6), pkt(7)], 'int16')               │
│                                                                              │
│  DC Link Voltage:                                                            │
│    Raw ADC: 0-4095 → Actual: 0-96 V                                        │
│    Scaling: Vdc_V = adc_count * 3.3 * 46.4545 / 4095                       │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

┌─ IMPORTANT FORMULAS ──────────────────────────────────────────────────────┐
│                                                                              │
│  Phase Current Conversion (raw ADC → Amps):                                │
│    offset = 2041 (powered) or 182 (unpowered)                              │
│    Ia_amps = (adc_a - offset) * (3.3/4095) / (0.002 * 20)                 │
│    where 0.002 = sensor gain (V/A), 20 = amplifier gain                   │
│                                                                              │
│  d/q Current From Packet (int16 → Amps):                                   │
│    Id_amps = double(typecast(uint16([pkt(18), pkt(19)]), 'int16')) / 3276.7 │
│                                                                              │
│  Voltage From Packet (int16 → Volts):                                      │
│    Vd_volts = double(typecast(uint16([pkt(26), pkt(27)]), 'int16')) / 6553.4 │
│                                                                              │
│  Angle From Packet (uint16 → Radians):                                     │
│    theta_rad = (double(pkt(22))*256 + pkt(23)) / 65535 * 2 * pi           │
│                                                                              │
│  Speed From Packet (int16 → RPM):                                          │
│    speed_rpm = double(typecast(uint16([pkt(6), pkt(7)]), 'int16'))        │
│                                                                              │
